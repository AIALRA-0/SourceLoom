# SourceLoom 处理器：阅读与材料管理

## 1 启动和数据

使用 README 的本地安装步骤，运行 `python -m sourceloom.cli serve`，打开输出的本机地址；默认端口为 8765，首次安装材料库为空，不需要私人快照或账号才能启动

`SOURCELOOM_DATA` 指定数据目录，`SOURCELOOM_CONFIG` 指定本机私有配置；启动时沿用同一数据目录，目录中的原件、资源、版本和请求记录才会持续可用。停止服务后再进行数据位置迁移，不把数据库、配置或浏览器记录提交到公开仓库

需要读取经过核对的历史快照时，可以显式执行 `python scripts/processor_user_entry.py --data <snapshot-directory> --port 8765`；此入口要求快照清单和数据库均存在，不会自动选择某个开发者的材料库

## 2 材料树

- 单击选择，双击或 Enter 打开；方向键只移动焦点或展开目录，不加载每一份材料
- F2 重命名，Escape 取消，Shift+F10 或行末菜单打开操作；长名称可查看完整路径
- Ctrl／Shift 多选后可移动或移至回收站；拖入文件夹与「移动到」使用同一管理操作
- 拖动时核对完整目标路径，等待服务端确认后的成功反馈；未知结果查询原操作，不重复提交
- 改名和移动只改变管理信息，原 ID、正文标题、版本、书签和资源保持
- 归档是暂时收起，回收站是可恢复删除；永久删除另行确认，不删除远端 ReadWeave 笔记
- 示例只读，试用副本才进入个人材料库；干净安装不附带私人示例

## 3 双栏阅读

原件与成稿都连续滚动；页码显示当前阅读页，翻页和输入页码是在连续文档中跳转

- 「自由」：两侧独立，分别记住位置
- 「连锁」：点击后立即以最近操作侧对齐另一侧，之后双向跟随
- 再次解锁只停止跟随，两侧停在当前位置；「返回上次独立位置」单独执行
- 左侧查找、页码和倍率用于原件，右侧排版用于成稿；连锁不要求倍率相同
- 原生文字层支持选择和复制；扫描页没有文字层时只提供原页参阅，不冒充已经识别
- 「定位」可以打开成稿目录和本地配对；只有页级来源时如实标为近似，不用全文百分比伪装对应

书签按材料、原件与成稿版本分别保存，记录原页及页内位置、正文块及块内位置；刷新、字号和分栏变化后恢复逻辑位置

## 4 交接与版本

下载一个完整任务包，复制固定开始指令，在具有文件工具的模型会话中处理；默认使用自己的档位，不要求另换 Pro。必须确认会话实际解包、读取正文并查看必要图像；xhigh 真会话单包能力仍待完整验证

通过正常导回入口接收 Markdown，程序恢复资源并保存版本；原件和原始返回保留。编辑基于当前版本，过期预览、另一窗口的更新和撤销都应先核对版本，不能覆盖后来的修改

## 5 问题与交付

问题入口显示实际数量，打开后查看原件与成稿预览，再选择确认表示、局部处理或稍后处理；确认当前版本关系不等于证明全文语义忠实

阅读包可直接导出。配置自己的 ReadWeave 地址、凭据和目标后才能实际导入；已有可靠笔记身份时提供打开动作，未知请求保留原回执，不因界面刷新再次导入

机械检查通过仅表示文件、资源和格式可用，Candidate 状态仍可阅读和交付；本轮没有新增全文语义审核或升级为 Verified。ReadWeave 页面初始化性能属于独立产品范围，本地阅读不等待它
