# 可复用的发布检查经验

## 1 私有发现结果不能进入公开说明

部署和历史调查会产生比源代码更敏感的资源索引、原始消息和诊断输出

本项目把这些资料保存在忽略目录，公开报告只保存合成样本、公开来源和经过核对的结论，提交前检查实际暂存内容与提交元数据

## 2 原文引用必须成为真实可见内容

生成者可以引用正确源对象，但渲染器如果没有插入该类对象，元数据覆盖率仍会看起来完整

本项目已增加原文本体插入，并将实际渲染结果交给审核角色；复查受保护源文是否可见，不能只检查身份集合

## 3 已知配置错误与未知结果分别恢复

服务健康但暂停接单、模型使用默认高强度思考而耗尽输出额度，都是已经实际遇到的不同失败

前者检查接单状态，后者记录用量并修正对应角色配置；未知状态保留原调用身份，不能自动创建第二个生成任务

## 4 截图与发布对象一起核对

截图可能包含用户名、材料标题、通知和内部地址，即使图片文件没有元数据也需要查看像素

本项目只发布合成材料页面，未来替换截图时重新核对具体画面，不继承旧图片的检查结论
