# 连贯讲解与材料库迭代

本轮根据用户确认的计划实施，教学方法参考相邻课程项目的实际规则，写作规范仍以完整中文写作技能为准

## 1 怎样把知识讲连贯

旧流程要求每个单元固定安排七个阶段，却没有充分约束前一段怎样帮助读者理解后一段，容易生成栏目齐全、读起来跳跃的文章

新的规划先说明读者要解决的问题，再安排理解下一步所需的前提、具体过程和学完后能作出的判断，七类教学要求仍需逐项安排，但不再对应七个固定标题

- 规划角色说明每个主题依赖哪些前文，以及为什么需要接着讲它
- 写作角色收到整篇安排、前面实际生成的正文和当前单元的完整来源，不能把尚未讲过的内容称为“前面已经说明”
- 教学审核对照成稿检查必要前提、具体示范、概念使用、适用范围和相邻正文的连接，每个判断引用实际正文
- 结构问题交回规划角色，再由写作角色重新生成受影响的单元，未受影响的单元保持不变
- 写作规则和原信息保留另行核对，教学审核通过不代替它们，正文变更会使旧审核失效

完整技能包会保存在运行目录，每个角色收到全部有效规则正文，支持文件工具的通道还可以读取实际技能文件，不把传入路径当作已读取证明

## 2 页面信息怎样完整保留

页面标题、路径和侧栏配置可能需要保留，却不一定帮助读者理解正在讲解的主题，把它们插入概念教学中途会打断思路

规划可以明确把这类页面信息安排在文末，系统同时绑定它们对应的全部原信息，不能因为移动位置就漏掉内容

- 只有接入时识别为页面信息的对象可以走这条安排
- 正文事实、限定条件、公式和图表不能伪装成页面信息移走
- 原材料本来就在讲页面配置时，规划和教学审核仍需检查它是否属于主线，类型检查本身不能代替这一判断
- 文末内容随正文保存和导出，不是仅在内部记录中保留

## 3 从课程项目借鉴了什么

本轮直接阅读了课程项目的教学蓝图、生成规则及对应实现，借鉴的是内部组织方法，没有复制私人课程材料

- 内部规划指导解释，不要求正文暴露规划字段和固定栏目
- 先建立具体问题，再补理解这个问题所需的前提，随后讲清变化过程和可观察结果
- 前后连接必须来自真实内容关系，不能只增加“接下来”等连接词
- 按材料的实际用途调整解释，图片、表格、代码和公式需要不同的阅读起点

源织仍保留自己的完整性要求，装饰对象、重复出现和页眉不能因为教学价值较低就被静默删除，旁边能够打开原件也不能代替正文解释

## 4 文件库怎样使用

材料保存在后台，关闭或刷新浏览器不会清空已经保存的原件、正文和任务

1. 导入材料后放入文件夹，点击材料名称打开正文
2. 在材料或文件夹上右键，选择重命名、移动或移到回收站，触屏可以使用行末的更多操作按钮
3. 用方向键在树中移动焦点，用 `F2` 重命名，用 `Shift+F10` 打开当前项菜单
4. 按住 `Ctrl` 或 `Command` 选择多项，使用移动或回收站操作统一处理
5. 从回收站恢复文件夹时，恢复本次删除的材料和原层级，之前单独删除的材料仍留在回收站
6. 打开编辑窗口修改正文，系统自动保存新版本，历史版本可以恢复

两个页面同时修改时，后提交的旧版本不会覆盖服务器的新版本，本页输入会留在浏览器中供核对

后台只更新状态时，正文页面保持原来的实例和阅读位置，侧栏宽度及文件夹展开状态也会保存

彻底删除会移除材料库记录及其历史版本，无法通过本应用恢复，服务器文件和外部备份不会因此被安全擦除，费用记录继续保留

## 5 已验证的范围

- 浏览器实际完成正文自动保存与重开、并发编辑冲突、键盘重命名、右键移动和整层文件夹删除与恢复
- 实际检查了后台刷新不会重新加载未变化的正文，手机宽度没有页面级横向溢出
- 程序反例覆盖教学前提倒置、缺少正文连接证据、错误文末归类、局部修复越界、文件夹循环和批量版本冲突

这些检查证明对应程序行为，不能代替模型生成效果，真实原文与自动输出的进展继续记录在 [真实试验记录](../reports/AUTOMATIC_TRIAL.md)

## 6 时间和费用的约束

180 分钟是助手此前提出的试验总时限，不是用户设定的要求，本轮已经取消由这一时限造成的生产暂停，不再据此要求追加时间授权

单次网络请求仍保留超时处理，费用、调用次数和未知结果继续累计，结果不确定时查询原请求，不能靠重新创建材料或重启服务绕过预算

输入结构的自动修复只允许调整可验证的结构关系，不允许顺带改写正文，完整生成结果仍需经过教学、写作规则和原文对照三方面的检查

## 7 怎样取得同一批真实输入

本轮 24 份材料的原始地址和文件摘要保存在 [材料目录](../evals/real-corpus.json)，可以使用以下命令下载到默认忽略目录

```bash
# 获取目录中的原始输入，不启动模型生成
python scripts/fetch_real_corpus.py
```

下载后在材料库中选择「导入材料」，找到 `.local/real-corpus` 内的文件，保存后打开原件核对

来源更新时，下载器会将新版本另存并明确报告差异，不会把它当作历史试验使用的同一份原件，下载成功也不代表材料改写成功
