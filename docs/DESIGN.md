# SourceLoom 当前设计采用事实

2026-10-09，用户明确要求采用 APCF Design 规则与模板风格。本轮采用 `tool-workbench-2.3.1`，状态为 **ADOPTED**；采用不等于用户已认可最终界面。

权威来源为 APCF Core v0.3.0 Closeout v2 的 `design/INDEX.md`、`design/RULES.md`、`design/VERIFICATION.md` 和对应 Profile。发行包 SHA-256 为 `4d41a3dd8a5516498776cf2563de47730017bd2a4f3052e757d12fa9eb4f1dda`。Profile 规范版本为 2.3.1，界面参数版本为 2.3.0；原参考实现仅用于比较，未替换 SourceLoom 的业务数据模型。

项目实现事实来源：`sourceloom/static/processor_tokens.css` 保存由 Profile 派生的角色参数；`processor_workspace.css` 与 `processor_workspace.js` 负责实际模板壳、面板布局和材料标签；`processor_workbench.css` 负责阅读与共享控件；各处理器模块继续管理材料、阅读、版本与问题。`processor_select.js` 和 `processor_icons.js` 采用参考组件，并适配现有表单与动态控件。共享规则正文不复制到项目说明、Prompt 或 Skill。

适用范围包括工作台活动栏、材料树、交接、阅读、问题处置、菜单、设置和浮层，关联 D01–D16。项目不需要模板演示中的节点画布、样例内容或演示本机文件数据库；这些不是 SourceLoom 产品功能。

明确差异：

- 阅读正文保留现有 18 px 默认及用户保存的字号、行距，依据为已接受的长文阅读习惯。UI 字号、控件和树行使用 Profile 角色参数；不会以同化为由覆盖用户阅读偏好。
- 原 PDF 页与研究图保持原色和原有文字层。深色模式改变工作台及浏览器成稿视图，不修改原件、原始返回、保存正文或 ReadWeave 导出字节。
- 材料与检查器使用同一份面板节点，可交换左右位置；中屏右面板与窄屏面板进入可关闭的原生抽屉；原件与成稿继续使用已有连续双栏、连锁与单栏阅读模式，不把它们替换成模板占位文档。
- 当前采用事实在源码中记录；VPS 上一次只读 Pilot 的 `UNRESOLVED` 属于旧轮次状态。本轮未经部署不声称线上已采用新界面。

实际用户验收、测试数量和部署状态只由当前验收报告说明。本文件不宣称完整可访问性认证、真实设备 INP 或模型生成质量通过。

## 2026-10-09：实际模板架构接入

上一候选只完成外观与部分控件适配，不能称为完整模板采用；本轮替换实际主布局，保留先前证据而不追认其架构结论。

`#app` 三行承载顶栏、工作区和状态栏；工作区为活动栏与五列布局；中央面板固定材料标签、路径／内容视图、独立主内容与保存页脚。原件、交接、成稿是中央业务页，材料标签按稳定材料 ID 管理，两者不共用事件属性。

模板职责包括面板迁移、宽度预算、指针取消、键盘调整、抽屉、焦点返回、布局偏好、材料标签与检查器。树保留真实选择、目录、拖放及服务；检查器可查看已选择对象与实际版本，选择不触发材料打开。旧 app-shell、固定侧栏及树宽度控制器已撤下，既有 PDF／正文控制器保留。

仅移植模板适用于产品的结构和交互；演示本地材料库、画布、模拟版本与简化 Markdown 解析器不采用，真实业务仍由 SourceLoom 管理。示例目录、远程认证、ReadWeave 交付与生成通道不以此次布局验收替代。


## 2026-10-09：顶部与窄栏修正

阅读时文档身份与动作复用模板主工具栏。空间足够时处理步骤、版本、导回、下载、编辑和交付使用可直接操作的图标，提供悬停及键盘说明；依据实际中央面板宽度逐级折叠次要项，编辑仍直接可达。切回原件准备或交接时，原步骤节点回到模板工具区。不会克隆业务按钮或生成第二套操作状态。

阅读工具按中央内容容器宽度适配。窄栏把视图、阅读模式与当前面板工具放在一行，原件次要工具及手机页码跳转进入已有工具菜单；宽栏恢复原节点。编辑入口在窄栏打开实际编辑面板，不只切换隐藏面板的状态。正文仍保留用户阅读字号。

活动栏和材料树用中性背景、文字及独立键盘焦点表达状态，不再使用左侧选中亮边。树行背景保留两侧留白，并随节点层级向内缩进，不铺满整棵树。阅读主区使用全部中央面板宽度，正文行宽仍由阅读偏好控制；浮层只覆盖内容，不占用布局列，左右定位不能同时约束其宽度。中央及侧栏页脚共享已采用 Profile 的 footer-height 角色。实际视觉与部署结果由当前轮次证据说明，不把模板采用写成用户已经认可。
