# 历史生成服务模板

这里保留旧任务需要的 Worker 模板，不属于当前处理器正常部署。只读查看历史任务、新材料手动交接、原件解析与成稿导回都不需要启动这些服务。

- `sourceloom-worker.service`：旧持久生成 Worker。
- `sourceloom-eval-worker2.service`：旧第二 Worker。

模板原样保留以便核对历史运行方式，不能因为本目录存在就自动安装或启用。确需恢复已授权的历史任务时，先核对任务身份、UNKNOWN／费用、原配置与当前程序兼容性，避免与处理器迁移或同库写入冲突；旧任务的外部写作 Skill、私有通道与预算另行确认。

当前网页服务、身份保护、迁移与回滚以 [生产部署说明](../README.md) 为准。
