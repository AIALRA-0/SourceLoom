## 1 先看当前结果

源织保存原件，按独立角色清点、规划、生成、审核和局部修复，再交给 ReadWeave 阅读；默认按原文主旨改写，改善表达和衔接，不自行设计课程情境、练习或拓展

新任务先完成规划再分批写作，出现问题时只对具体位置提交补丁；生成前需要明确四类信息：

- 改写允许和禁止改变的范围
- 必须保留的全部源信息
- 理解后文需要先掌握的概念
- 文章结构与段落之间的关系

实际实现、真实样例和验证范围见 [主动编排实施记录](docs/ACTIVE_COMPOSITION_IMPLEMENTATION.md)

阅读页提供以下操作：

- 通过统一工具栏编辑正文、下载材料或查看历史版本
- 点击两侧关联段落，在原文与改写之间定位
- 配图默认折叠，可以一起展开或折叠

此前试验结果保留在 [历史输入与结果](docs/ITERATION_8.md)、[性能对照](docs/ITERATION_6.md) 和 [工作台更新](docs/ITERATION_4.md)

## 2 怎样使用

1. 点击「导入材料」选择文件或填写网页地址，上传期间会显示实际发送进度
2. 选择左侧文件夹，提交后等到服务器确认保存，再关闭页面
3. 已配置生成通道时可在导入时选择自动改写，也可以保存后再生成，后台继续处理，材料页显示当前阶段和正在处理的部分
4. 再次打开材料，选择「并排对照」查看输入和已有输出，点击任一侧的已关联文字可以定位另一侧，多来源可以逐项选择，停止的任务仍保留已经产生的草稿
5. 下载正文，或将具备导出条件的候选包送入 ReadWeave

可以重命名、移动、创建副本、移到回收站或恢复材料，手动编辑正文会保存新版本并撤销旧的通过状态

文件树支持右键、键盘、多选和整层文件夹恢复；编辑器支持语法着色、行号、查找替换、撤销、预览、自动保存和冲突恢复，标题编号可以选择沿用、显示或隐藏，详见 [本轮改写与工作台更新](docs/ITERATION_4.md)

上一轮长材料的调用预检、原文定位方式与性能复测见 [历史改进记录](docs/ITERATION_3.md)

## 3 在本机启动

需要本机能够运行 `python` 命令，版本至少为 3.11

1. 在仓库目录创建独立运行环境

```bash
# 创建项目自己的运行环境
python -m venv .venv
```

2. 激活环境，Windows 使用 `.venv/Scripts/Activate.ps1`，其他系统使用 `source .venv/bin/activate`
3. 安装程序

```bash
# 安装本仓库的程序与依赖
python -m pip install .
```

4. 启动网页服务

```bash
# 启动材料库页面，默认仅供本机访问
python -m sourceloom.cli serve
```

5. 浏览器打开命令输出的本地地址，默认端口为 `8765`
6. 在使用相同配置与材料目录的第二个终端启动后台处理

```bash
# 后台读取已保存的任务，独立于浏览器执行
python -m sourceloom.cli worker
```

未配置模型时可以保存和管理材料，自动生成会说明缺少通道

## 4 完整写作技能与模型配置

1. 把 [配置示例](config.example.json) 放在私有位置
2. 通过 `SOURCELOOM_CONFIG` 指定配置文件
3. 通过 `SOURCELOOM_DATA` 指定材料目录
4. 将完整的 [中文技术写作技能](https://github.com/AIALRA-0/agent-human-readable-technical-writing) 目录填入 `writing_skill_dir`

每个角色收到全部有效规则正文，完整技能包同时冻结保存，详见 [实际部署方式](docs/SKILL_RUNTIME.md)

模型收到规则不等于已经遵守；新流程分别记录原件与结构检查、当前批次模型核对、整篇独立语义核对和用户接受，保存成功不会被标成绝对无损证明

自动生产默认使用以下处理设置，这些设置用于阻止死循环和意外的按量付费，不代表用户的订阅额度

- 订阅请求与按量付费请求分别记账，订阅请求不受按量调用次数限制
- 默认不设整篇或项目总时限，单次网络请求仍有限时处理
- 新流程每批次最多两轮局部补丁；内容与格式问题优先合并修复，达到上限时保留正文和具体问题；旧任务沿用冻结的旧流程与配置
- 使用人民币保护时，需要配置供应方的人民币输入、缓存输入和输出单价；旧美元记录保持原币种，不换名

订阅累计调用次数默认不设上限，内容生成与修复优先使用深度求索

每 1,000 个原文字符约 0.1 元是长期优化口径，不是删减信息、压缩固定字数或提前终止复杂材料的硬门槛

完整试验预算与未知订阅成本见 [试验记录](reports/AUTOMATIC_TRIAL.md)

## 5 已验证范围与限制

- 文件夹、材料管理、版本保存、回收站及后台任务恢复有程序测试覆盖
- 网页保存原始内容与限量获取的图片，缺失资源保留为缺口，动态页面和所有图形类型尚未全面支持
- 普通文稿可提取文字、表格、链接与资源，复杂公式、修订痕迹和无法可靠转换的对象仍显式保留缺口
- 实际上传测试覆盖关闭页面后重新打开、原件下载一致性、已有新稿下载与阶段进度，模型返回格式错误时不冒充生成完成
- 专用混合文档完成 ReadWeave 实际导入、保存和重开，重复图片、表格、代码、公式、段落身份与脚注目标均通过该例核对
- 多领域留出材料的批量质量与人民币成本校准仍按公开验收记录执行，不能用单篇结果推断全部材料

运行不调用付费模型的程序检查

```bash
# 安装测试依赖
python -m pip install ".[test]"

# 执行最多等待 120 秒的确定性检查
python scripts/verify.py
```

程序测试通过不能代替真实成文效果和用户实际阅读验收
